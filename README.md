# Novel-Chem-
Collaborative Project Novel Chem Web app

Kontribusi Saya

Dalam proyek kolaboratif ini, saya bertanggung jawab pada bagian Perancangan UI/UX dan Pengembangan Front-End aplikasi web ChemWik.

Adapun kontribusi saya meliputi:

- Merancang tampilan antarmuka (UI) dan pengalaman pengguna (UX) agar aplikasi mudah digunakan.
- Mengembangkan komponen dan halaman antarmuka menggunakan Vue.js dan JavaScript.
- Mengimplementasikan desain visual ke dalam aplikasi web.
- Mengembangkan elemen interaktif pada sisi Front-End.
- Berkolaborasi dengan anggota tim dalam mengintegrasikan Front-End dengan sistem Back-End.

Peran: Front-End Developer & UI/UX Designer

Teknologi: Vue.js, JavaScript, HTML, CSS

Jenis Proyek: Proyek Kolaborasi Tim
